实时语音播报

菜单栏常驻，后台轮询新消息并即时朗读，支持 macOS 系统语音降级兜底。

🎙️

Fish Audio 多音色

三个音色槽位 #1/#2/#3，可按通知类型指定音色；自动探测可用模型并标注免费。

🔑

统一 Token 鉴权

所有接口与后台共用同一个 Bearer Token，简单清晰，缺失即 401。

📡

REST 风格 API

标准资源命名 /api/notifications，增量游标拉取、播报回执、状态可观测。

🖥️

后台可观测

Web 后台查看每条消息三态（未读取 / 已读取未播报 / 已播报）、统计与一键测试。

⚡

Cloudflare 托管

Worker + D1 零运维部署，全球边缘运行，免费额度内即可上线。

快速开始

三步跑起来：部署后端 → 安装客户端 → 推送第一条消息。

1 · 部署后端（Cloudflare）

# 安装依赖并登录
npm install -g wrangler
wrangler login

# 创建 D1 数据库并初始化
wrangler d1 create notivoice
# 把输出的 database_id 回填进 wrangler.toml
wrangler d1 execute notivoice --local --file=./schema.sql
wrangler d1 execute notivoice --remote --file=./schema.sql

# 设置统一 API Token（任意随机值）
wrangler secret put API_TOKEN

# 部署
wrangler deploy

2 · 安装客户端（macOS）

1
获取 NotiVoice.app从 Release 下载，或本地 bash mac/build-app.command 打包。
2
拖入应用程序首次打开若被拦截：右键 → 打开，或在「系统设置 → 隐私与安全性」点「仍要打开」。
3
填写服务器地址与 Token服务器地址填你的域名（如 https://notivoice.laomo.app），Token 与后端一致。

3 · 推送第一条消息

curl -X POST 'https://notivoice.laomo.app/api/notifications' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer 你的TOKEN' \
  -d '{"text":"有新的 BTC 提醒","voice":2}'

打开菜单栏 App，几秒内即可听到播报。也可在 后台 用 Token 登录后一键发送测试。
